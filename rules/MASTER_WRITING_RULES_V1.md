# MASTER_WRITING_RULES V1.0

## AI文学大师实验室｜第一版文学宪法

> 定位：本文件不是"文风模板"，而是可执行的小说生产约束。
> 核心原则：不模仿任何单一作家；只吸收跨作家、跨时代仍成立的高级文学能力。
> 证据基础：本阶段综合此前研究的经典短篇及当前项目中的作品分析，重点包括契诃夫、莫泊桑、欧·亨利、海明威、鲁迅、莫言《透明的红萝卜》、史铁生《命若琴弦》等。

------------------------------------------------------------------------

## 0. 总原则：先让故事成立，再让文学性出现

### WR-001｜每一段文字必须至少承担一种功能

写完一段后标注其主要功能： - 推进事件 - 暴露人物 - 改变关系 -
释放/隐藏信息 - 建立场景 - 制造情绪 - 埋设意象 - 改变读者判断

如果一段只有"好看"，却不能改变上述任何一项，优先删除或重写。

### WR-002｜文学性不得靠解释获得

凡是可以通过人物行为、物件、动作、对白、环境声音完成的情绪信息，不优先由作者直接总结。
但如果人物需要真实而复杂的内心活动，允许直接心理描写；标准不是"禁用心理"，而是"避免替读者把意义说完"。

### WR-003｜每个重要场景必须有"关系变化"

进入场景前 A 与 B 是一种关系，离开时至少有一个维度发生变化： - 更亲近 -
更疏远 - 权力倒置 - 误解加深 - 秘密暴露 - 欲望增强 - 欲望受挫

如果关系完全不变，场景大概率只是填充。

------------------------------------------------------------------------

# 一、人物与故事

### WR-101｜人物必须拥有"欲望---阻力---选择---代价"

设计重要人物时写清四项： 1. 现在想得到什么； 2. 什么阻止他得到； 3.
他最终主动选择什么； 4. 选择后失去什么。

禁止只写"人物性格很复杂"。

### WR-102｜人物必须同时存在至少一个外部目标和一个内部需要

外部目标推动情节；内部需要制造矛盾。 两者最好不完全一致。
例如：人物想"留下钱"，但真正需要的是"承认自己已经无法挽回过去"。

### WR-103｜不要用背景介绍代替人物塑造

人物首次出现时，优先通过一个选择、一个动作、一个关系现场或一个具有指向性的物件建立人物。
履历只在会改变读者判断时出现。

### WR-104｜让人物通过"做错一件符合其性格的事"暴露自己

不要为了制造冲突让人物突然降智。
冲突应从人物自身的欲望、恐惧、习惯、偏见中自然生长。

### WR-105｜人物必须有一个不能轻易改变的核心惯性

故事可以改变人物，但变化必须有代价、有积累。
避免"听了一句话就顿悟""发生一件事就彻底变好"。

------------------------------------------------------------------------

# 二、冲突

### WR-201｜优先制造价值冲突，而不是事件冲突

事件冲突：两个人争一个东西。
高级冲突：两个人都在保护自己认为不可放弃的东西。

写冲突时问： \> 如果双方都认为自己有道理，冲突是否仍然成立？

如果答案是否，冲突偏薄。

### WR-202｜冲突必须逐级改变赌注

至少经历： 事实冲突 → 关系冲突 → 自我认知冲突。
不要只增加声音、动作和暴力强度。

### WR-203｜最强冲突常来自"不能说"

设计一个场景时，写出： - 人物想说什么； - 人物不能说什么； -
人物因此说了什么替代话。

第三项就是潜台词的主要来源。

------------------------------------------------------------------------

# 三、叙事距离与视角

### WR-301｜每个场景先确定叙事距离

选择： - 远景：看整体、社会关系； - 中景：看行为、关系； -
近景：进入感官与心理； - 极近：只保留某个瞬间、物件或身体反应。

不要在一句话内无意识跳跃。

### WR-302｜信息量由人物的"知道程度"控制

作者知道得多，不等于读者必须知道得多。 原则： \>
让读者知道"足以产生判断"的信息，而不是"足以解释全部"的信息。

### WR-303｜重大信息优先通过行动后的后果呈现

如果秘密会改变读者对人物的判断，不急着先解释秘密。
先让读者看到异常行为，再逐步补信息。

### WR-304｜不要用悬念替代人物

"他到底做了什么"只是信息问题。 更高级的问题是：
"他为什么明知会失去这个东西，仍然这么做？"

------------------------------------------------------------------------

# 四、场景

### WR-401｜场景必须有具体空间压力

不要只写"在房间里争吵"。 至少确定： - 人物站/坐在哪里； - 谁离门更近； -
谁掌握某件物品； - 什么声音打断他们； - 谁能离开、谁不能离开。

空间关系会自然产生权力关系。

### WR-402｜用少量高辨识度细节建立世界

一个场景优先选择 2---4 个具有功能的细节。 细节必须至少完成一项：
人物化、时代化、阶层化、情绪化、伏笔化、象征化。

不要为了"真实"堆砌百科资料。

### WR-403｜优先写人物正在接触的东西

人物拿什么、擦什么、藏什么、舍不得丢什么，往往比作者介绍人物更有力量。

------------------------------------------------------------------------

# 五、细节与感官

### WR-501｜细节必须改变读者判断

删掉细节后，读者对人物、环境或情绪的理解如果完全不变，该细节优先删除。

### WR-502｜感官描写必须服务叙事

优先顺序： 触觉/声音/气味 → 行为 → 联想 → 意义。
不要把感官描写写成纯粹摄影。

### WR-503｜反复出现的物件必须发生意义位移

第一次：普通物件。 第二次：与人物欲望绑定。
第三次：改变意义或成为结尾余味。 禁止"道具只出现一次却被称为意象"。

------------------------------------------------------------------------

# 六、意象

### WR-601｜意象不要解释

不要写： "这轮月亮象征着他的孤独。"
改写为让月亮、声音、物件、天气与人物行为产生关系。

### WR-602｜意象至少经历一次变形

同一意象再次出现时，最好发生至少一项变化：
位置变化、状态变化、人物关系变化、读者意义变化。

### WR-603｜意象优先来自故事内部

最好的意象通常是人物已经在使用、触摸、逃避或等待的东西，而不是作者后来强行加上的"文学符号"。

------------------------------------------------------------------------

# 七、情绪

### WR-701｜情绪必须有路径

重要情绪至少写出： 触发 → 身体/行为反应 → 抵抗或伪装 → 变化 → 后果。

不要从"他很悲伤"直接跳到"他很绝望"。

### WR-702｜允许人物不按作者预期表达情绪

悲伤的人可能整理桌子；羞愧的人可能开玩笑；害怕的人可能变得粗暴。
优先寻找人物自己的表达方式。

### WR-703｜情绪高峰后不要立即解释

高峰后可留下一个动作、物件、声音或空间。 让读者完成最后一步。

------------------------------------------------------------------------

# 八、节奏

### WR-801｜节奏不是"快慢"，而是信息密度与情绪压力的变化

连续高强度会麻木读者。 连续低强度会失去牵引。 在高潮前后安排密度变化。

### WR-802｜对白场景用动作打断节奏

人物说话时，加入必要的： 拿东西、点烟、喝水、擦拭、看向某处、停手。
动作不是装饰，而是人物无法直接说出的心理外化。

### WR-803｜删除重复信息，保留重复意义

同一事实不要说两遍；同一情绪可以通过不同形式重复。
"信息重复"通常低效，"意义回响"可以高级。

------------------------------------------------------------------------

# 九、语言

### WR-901｜优先准确、具体、有动作的词

能写"把杯子推过去"，不要写"以一种复杂而微妙的方式表达友善"。

### WR-902｜警惕AI腔句式

高风险模式： - "这一刻，他终于明白......" - "仿佛......" -
"似乎......" - "空气中弥漫着一种......" - "一种说不清道不明的......" -
连续排比形容词； - 句句都漂亮； - 人物说话像作者。

不是禁用这些词，而是连续、无功能地使用时必须重写。

### WR-903｜语言风格应由人物、地域、时代、叙事距离共同生成

不要给整篇小说预设一个"高级文风"。
先确定谁在看、谁在说、谁在感受，再决定句子的质地。

------------------------------------------------------------------------

# 十、对白

### WR-1001｜每段重要对白都必须回答五问

1.  表层意思是什么？
2.  潜台词是什么？
3.  人物真正想得到什么？
4.  谁掌握权力？
5.  对话结束后关系发生什么变化？

答不出来就重写。

### WR-1002｜人物不要直接说出自己真正的目的

除非人物有充分理由坦白。 优先让人物绕开核心，说另一件事。

### WR-1003｜对白必须有信息差

至少一方不知道另一方掌握什么。 双方完全透明时，重要对白容易变成说明书。

------------------------------------------------------------------------

# 十一、主题

### WR-1101｜主题必须从人物选择中长出来

先问： \> 人物为了得到 X，愿意牺牲 Y 吗？

再从选择结果归纳主题。 禁止先写一句"主题是人生无常"，再寻找情节证明它。

### WR-1102｜不要让人物替作者总结主题

结尾尤其禁止： "这就是人生。" "原来生活就是......"
"他终于明白了爱的意义。"

除非这种总结本身就是人物性格或叙事策略的一部分。

------------------------------------------------------------------------

# 十二、留白

### WR-1201｜留白不是删信息，而是保留解释空间

可以隐藏： 动机的一部分、情绪的名称、未来结果、人物真正想法。
但不能隐藏所有因果，否则变成模糊。

### WR-1202｜让读者能够提出至少两种解释，但其中一种更有证据

高级留白不是"什么都可以解释"，而是"多解但不失重心"。

------------------------------------------------------------------------

# 十三、结尾

### WR-1301｜结尾必须改变前文意义，而不是只停止故事

检查： 最后一个场景是否让读者重新理解前面的某个细节？

### WR-1302｜最后一击优先使用行动、物件、声音、画面

能用一个动作结束，就不要用三段主题总结。

### WR-1303｜不要为了震撼制造反转

反转必须来自前文已经存在但读者尚未重新组合的信息。
如果删除反转，人物仍然成立；如果加入反转，人物更深------才值得保留。

------------------------------------------------------------------------

# 十四、A/B/C/D/E 迁移原则

## A｜跨大师共同规律：可以进入生产规则

-   人物欲望与选择驱动故事；
-   冲突来自人物关系和价值；
-   细节承担人物/情绪/时代功能；
-   信息控制决定阅读张力；
-   对白存在潜台词；
-   意象与人物行动绑定；
-   情绪通过过程呈现；
-   结尾留下后续心理运动；
-   主题由故事证明而非作者宣布。

## B｜作者特征：只作为"案例库"，不得变成模板

例如： - 鲁迅的反讽叙事与社会批判； -
莫言强烈的感官、乡土身体性与幻觉化经验； -
史铁生的哲学寓言化与生命思考； - 海明威的冰山式克制； -
欧·亨利的结构性反转； - 契诃夫的日常性、开放性与人物复杂度。

这些可以学习机制，但不得要求新小说"像他们"。

## C｜时代因素：不得机械复制

具体政治制度、乡土社会结构、传统伦理、革命语境等，应在现代故事中重新转换。

## D｜类型因素：按类型重新权衡

悬疑可提高信息控制；爱情可提高关系变化；喜剧可提高误解与节奏；文学现实主义可提高人物与生活纹理。
不同类型不是不同文学宪法，而是不同参数。

## E｜不可简单迁移

-   古典章回套语；
-   强烈时代政治口号；
-   某些特定方言/地域表达；
-   为反转服务的过度结构技巧；
-   与旧时代阅读习惯绑定的作者介入方式。

------------------------------------------------------------------------

# 十五、生产前强制检查

每篇小说开写前，回答： 1. 主角此刻最想要什么？ 2. 他最怕失去什么？ 3.
他为什么得不到？ 4. 如果得不到，他会做出什么错误选择？ 5. 谁会因此受伤？
6. 哪个秘密会改变读者判断？ 7. 哪个物件可以承载故事的一部分意义？ 8.
最重要场景中谁拥有权力？ 9. 哪一句对白表面无关、实际最关键？ 10.
结尾会让读者重新理解什么？

答不出来，不得进入正式初稿。

------------------------------------------------------------------------

# 十六、最终原则

> 不追求"像大师"。
>
> 追求大师共同拥有的能力：准确观察、复杂人物、真实冲突、精确细节、克制叙述、有效信息控制、潜台词、结构必然性、意象回响、开放结尾，以及让读者在故事结束之后仍继续思考的能力。
